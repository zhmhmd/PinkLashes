Pink Lashes — Веб-платформа для студии красоты

Профессиональное веб-приложение для автоматизации работы студии красоты. Проект включает в себя клиентскую часть для ознакомления с услугами и онлайн-записи, а также административную панель для управления бизнес-процессами.
 Технологический стек

Проект разработан с использованием современного стека технологий на Python:

    Backend: Django 4.x / 5.x — основной веб-фреймворк.

    Database: PostgreSQL — для надежного хранения данных о записях и клиентах.

    Frontend: HTML5, CSS3 (возможно Bootstrap/Tailwind), JavaScript.

    Deployment: Docker & Docker Compose для контейнеризации.

    Task Queue: Redis + Celery (если используется для уведомлений о записях).

 Основной функционал

    Каталог услуг: Удобное отображение категорий услуг (ресницы, брови и т.д.) с описанием и ценами.

    Система онлайн-записи: Интуитивно понятный интерфейс для выбора мастера, даты и времени посещения.

    Галерея работ: Портфолио мастеров для демонстрации результатов.

    Личный кабинет клиента: История записей и управление активными визитами.

    Админ-панель: Управление мастерами, графиком работы, услугами и мониторинг входящих заявок.

 Установка и запуск
1. Клонирование репозитория
Bash

git clone https://github.com/zhmhmd/PinkLashes.git
cd PinkLashes

2. Настройка переменных окружения

Создайте файл .env в корне проекта:
Code snippet

SECRET_KEY=your_secret_key
DEBUG=True
DB_NAME=pinklashes_db
DB_USER=postgres
DB_PASSWORD=your_password
DB_HOST=db
DB_PORT=5432

3. Запуск через Docker (рекомендуется)
Bash

docker-compose up --build

4. Локальный запуск (без Docker)

    Создайте и активируйте виртуальное окружение:
    Bash

    python -m venv venv
    source venv/bin/activate  # venv\Scripts\activate для Windows

    Установите зависимости:
    Bash

    pip install -r requirements.txt

    Примените миграции и запустите сервер:

Bash

   python manage.py migrate
   python manage.py runserver

 Архитектура проекта

    core/ — основные настройки проекта.

    apps/ — приложения для управления услугами, мастерами и бронированием.

    static/ — стили, скрипты и изображения.

    templates/ — HTML-шаблоны страниц.
